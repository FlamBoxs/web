FLAMBOX STATIC WEBSITE

Files:
- index.html: page content
- styles.css: layout and visual design
- script.js: mobile menu, year, and entrance animations

CLOUDFLARE PAGES DIRECT UPLOAD:
1. Extract this ZIP on your computer.
2. Open Cloudflare Dashboard > Workers & Pages.
3. Choose Create application / Pages (wording may vary) > Upload assets / Direct Upload.
4. Give the project a name such as flambox.
5. Upload the extracted folder contents (index.html, styles.css, script.js) or the extracted folder if the interface accepts it.
6. Deploy. Cloudflare should assign a *.pages.dev address.

Before public launch:
- Replace hello@flambox.in in index.html with your actual business email.
- Replace concept project descriptions with real work as you complete it.
- Update service details and any company/legal information as needed.

This is a static HTML/CSS/JS site. No build command or framework is required.
